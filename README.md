# Space War

A fast-paced, dual-mode arcade space shooter built with HTML5 Canvas and vanilla JavaScript. Defend the galaxy across two different tactical arenas: the intense frontline barrier of **180° Mode** or the complete 360-degree chaos of **360° Mode**.

## Game Modes

* **180° Mode (Forward War Zone):** Enemies attack exclusively from the front. Focus on upgrading your forward firepower, managing your hull integrity, and holding the line against waves of incoming scouts, fighters, heavy cruisers, and bosses.
* **360° Mode (Open War Zone):** Total freedom of movement in an open sector. Enemies swarm from all directions, requiring you to constantly maneuver, dodge crossfire, and collect experience crystals to level up your ship.

## Features

* **Custom Upgrade System:** Level up during runs to pick powerful upgrades like Multi-Beam Cannons, high-caliber damage boosts, fire rate increases, speed multipliers, and hull repairs.
* **Boss Encounters:** Hardcore boss fights trigger at milestone levels, testing your reflexes and build choices.
* **Local Storage Tracking:** Your high scores, survival times, and total run counts are automatically saved for each mode.
* **Zero Dependencies:** Built entirely using pure HTML5, CSS3, and modern JavaScript with procedural Web Audio sound effects—no external image or audio assets required.

## How to Play

1. Clone or download the project files into a single local folder.
2. Open **`index.html`** in any modern web browser.
3. Choose your preferred game mode (**180°** or **360°**) and click **PLAY**.

### Controls

* **Move:** `WASD` or `Arrow Keys` (or use the on-screen virtual joystick on touch devices).
* **Auto-Fire:** Your ship fires automatically at the nearest enemy.
* **Pause:** Press `P` or click the Pause button.
* **Mute:** Press `M` or click the Sound toggle button.

## Project Structure

* `index.html` — The main navigation hub and stats dashboard.
* `180-game.html` — The standalone code and engine for the 180° mode.
* `360-game.html` — The standalone code and engine for the 360° mode.
